# Game changes

## Mechanic changes
- HMs can be forgotten. This is by #define P_CAN_FORGET_HIDDEN_MOVE         TRUE       // If TRUE, Pokémon can forget any move, even if it is an HM.

## Stats changes

We follow the stats changes from [Emerald Legacy](https://github.com/cRz-Shadows/Pokemon_Emerald_Legacy); thus we have the following changes for each species.

- Ekans:
    - HP: 40(+5)
    - Atk: 65(+5)
    - Def: 44
    - Spd: 60(+5)
    - SpAtk: 40
    - SpDef: 54

- Arboks:
    - HP: 62(+2)
    - Atk: 95(+10)
    - Def: 85(+16)
    - Spd: 90(+10)
    - SpAtk: 65
    - SpDef: 79
